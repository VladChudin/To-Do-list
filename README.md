# ToDo List App 📝

## Описание
Это простой и адаптивный ToDo List, реализованный на чистом JavaScript, HTML и CSS.
Проект предназначен для практики **DOM-манипуляций, работы с localStorage, фильтров и сортировки задач**, а также адаптивной верстки под разные устройства.

---

## Возможности

- Добавление, редактирование и удаление задач
- Пометка задачи как выполненной или важной
- Фильтры: все / активные / выполненные
- Сортировка по дате (новые/старые)
- Адаптивный дизайн (мобильные устройства, планшеты, десктоп до 1440px)
- Меню задач с действиями поверх всех элементов
- Сохранение данных в localStorage (после перезагрузки задачи не теряются)
- Фокус на поле ввода после добавления задачи

---

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
